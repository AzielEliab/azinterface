## Executive findings

1. **Function holds.** The download-tracker Worker is the counted tarball plus the public custody page. Humans stay on that page and on loopback `azinterface ui`. Agents stay on the one FragGate door (`slug=azinterface`). The not-live sentence is computed in-process from the same head, carrier order, and tail as runtime `currentAltInternetFact`. Caller-supplied `alt_internet_live` / `packet_path_live` values are ignored.
2. **Structure is three shells, one of which is a scaffold.** `workers/download-tracker/` is the public host. `azinterface/` is the local desk (suite, custody, mail handoff, URL fetch, overlay session). `mobile/` is a Flutter custody screen with README stubs for Android and iOS and no desktop project. There is no installed phone or desktop app in this tree.
3. **Hardening is local for the banner and open for the door proxy.** The homepage sentence is rendered from this repository. Proxied `/v1/fraggate/*`, `/v1/runtime/*`, and `/v1/mesh/*` return the runtime body unchanged. The suite installer will fetch any `https://` download URL the catalog names. The tarball has no published digest. The public response has CORS `*` and no Content-Security-Policy.
4. **Philosophy matches the not-live contract on the flags, and lags on the short honesty lines.** A new visitor sees the not-live sentence, the install steps, and OFF. “Installed” on the suite desk means a local program was found on this computer. [PR #23](https://github.com/AzielEliab/azinterface/pull/23) is open. It is not merged, and it is not an installed app.

Live read of `https://azinterface-download-tracker.vibelock.workers.dev/v1/page_cycle_status` (2026-10-05): `current` OFF, `living_presence` false, `integrity_ok` false, `software_count` 33, `domain_count` 11. The homepage HTML contains the false flags, “Softwares 42”, “The domain count stays 33”, and the public-worker mail / kernel / boot sentences. Response headers: `access-control-allow-origin: *`. No Content-Security-Policy, no `X-Frame-Options`, no `X-Content-Type-Options`, no Referrer-Policy, no Permissions-Policy, no Strict-Transport-Security on that response.

## 1. Function

### What the download-tracker exposes

Worker `azinterface-download-tracker` (`workers/download-tracker/`). Binding `ASSETS` serves `public/`. Binding `DOWNLOADS` is KV `AZINTERFACE_DOWNLOADS` (`c7f3fab13653463e8c84b534bcf745b6`). `AZIEL_RUNTIME` is a service binding to `aziel-runtime`, with HTTPS fallback `https://aziel-runtime.vibelock.workers.dev`.

| Path | What a person or agent actually gets |
|------|--------------------------------------|
| `GET /` | Counted view plus the custody HTML (cycle, genesis, integrity, witness, AZHome, QNS pair cites, Scorched Earth advisory, pipeline strip, 11-domain map, Live Nodes strip) |
| `GET /download` | HTTP 200 gzip of the named asset. Default `azinterface-0.1.0.tar.gz`. No redirect |
| `GET /install.sh` | Bash that downloads that tarball from this host, unpacks it, and `pip install -e .` |
| `GET /count`, `GET /stats` | View and download counters. `/v1` and `/mcp` do not increment them |
| `POST /event` | Increments a counter for a caller-supplied owner / repo / branch |
| `GET\|POST /v1/{op}` | Local custody engine. Single path segment only |
| `GET\|POST /v1/fraggate/*`, `/v1/runtime/*`, `/v1/mesh/*` | Proxy to aziel-runtime |
| `GET\|POST /v1/azpipe/arch` | Local alias of `pipeline_arch`. The rest of `/v1/azpipe/*` still proxies |
| `GET\|POST /mcp` | Pointer. `ok: false`. Agents use runtime FragGate |
| `GET /openapi.json`, `/ai`, `/llms.txt`, `/cite.json` | Docs and the cite record |

Catalog relation: Interface is the human UI before FragGate. It is one Softwares card (`slug=azinterface`) and it is **not** one of the 33 domain slugs. Hub Softwares tabs come from runtime `GET /v1/software`. This repo stores a snapshot of that list at `azinterface/data/softwares.json` (`count` 42, 42 slugs). `pipeline_arch().software_count` is `len(domain slugs)` and is **33**. Local JSON names the two numbers apart: `software_count` and `runtime_catalog_count`, with the note “This count is the runtime Softwares catalog. It is not software_count.”

Runtime `SURFACE_HONESTY.softwares` at `b7a91aa9` is **42**. That agrees with the snapshot. It does not replace 33.

### Install path

The homepage primary control copies these steps. It does not run them:

1. Download `azinterface-0.1.0.tar.gz` from `/download`.
2. `tar -xzf`, then `python3 -m venv .venv && pip install -e .`
3. `azinterface ui` on `http://127.0.0.1:8880`.

`/install.sh` is behind “Advanced / optional” and tells the reader to save the script and review it. Pipe-to-bash remains possible. The script does not check a digest.

The tree contains `workers/download-tracker/public/azinterface-0.1.0.tar.gz` (50,117 bytes). SHA-256 of that blob at this tip:

`0282a37a5edbdd8b8a15e0b148ebd5aabd0ffe8eaf78b10bc94c1e012c457a5b`

The homepage tells the reader to compare `sha256sum` with “a hash you trust.” It does not print this digest.

The local suite (`azinterface ui` → Start suite) is a second installer. It reads `GET /v1/software` when the network answers, otherwise the bundled 42-card snapshot. For a card whose command is missing, Start suite downloads `download_url`, unpacks zip or tar, and runs `pip install -e` or `npm install`. Path escape (`..`) is rejected. A digest is not checked. AZVPN with an empty catalog URL falls back to `https://github.com/AzielEliab/azvpn/archive/refs/heads/main.tar.gz`.

### How the not-live sentence is computed

Two copies of one algorithm:

- Worker: `workers/download-tracker/src/alt-internet-fact.js` `notLiveSentence()`
- Desk: `azinterface/packet_path.py` `not_live_sentence()`

Head (both, and runtime, and AZ-OS):

> An alternative internet is not live (alt_internet_live is false). A packet path is not live (packet_path_live is false).

Then, if the process cannot see `/sys/class/net` (or Node builtins are absent):

> This isolate cannot see host hardware (worker_hardware is false).

Otherwise, one clause each for `lan`, `wifi`, `bluetooth`, `rf`, `photon`. Absent hardware says `QNM-RADIO-ABSENT`. Present hardware says it is on **this** machine and is not a second device. A machine id from `/etc/machine-id` (32 hex digits) is named when present; otherwise `MESH-HOST-ABSENT`. The tail is the same nine sentences as runtime and AZ-OS: a packet that leaves this machine and arrives on a different machine id is still missing; a same-machine frame does not count; Cap-7 and `.aziel` stay names; WireGuard, OpenVPN, L3, kernel UDP, and TUN/TAP stay SLOT; public mail send, the kernel, and boot stay not live; the public door stays `FG-STUB`; isolation is single-node security-awareness; phoenix is a local wait and re-seal; that is not a loopback fence.

`path_report()` then forces `packet_path_live`, `alt_internet_live`, and `second_device` to false, including when the caller posts those keys as true (`tests/test_packet_path.py`). Cap-7, ICANN, and `.aziel` return `MG-NO-IP-EXIT` and the same false flags. The Worker has no `nodejs_compat` flag, so `process.getBuiltinModule("node:fs")` is absent and the **public page uses the isolate sentence**. A local `azinterface ui` on a machine with sysfs uses the carrier clauses. On the audit VM that sentence named LAN `enp0s3` at `172.30.0.2` and still kept every live flag false.

The homepage banner appends, after that sentence: mail send does not run on the public worker; the public worker does not run a kernel; boot does not run on the public worker; the host operating system stays the host operating system; AZNews can stand alone; 4DMap can stand alone; a story is a pin only after that story is read back.

AZNet’s domain row uses the computed sentence. AZMail’s row says mail send does not run on the public worker. AZ-OS’s row says the public worker does not run a kernel and boot does not run on the public worker. Other domain rows whose stored status is the word `live` are painted as “listed on aziel-runtime.” The JSON field on those rows is still the word `live`. That word is a catalog listing. It is not `alt_internet_live`, `packet_path_live`, `kernel_live`, or `boot_live`.

### Site state

Worker `createState().cycle_index` is `0`. Python `Engine.cycle_index` is `0`. Both map to **OFF**. Integrity starts false. Living presence is ON and integrity together. The sealed order is `OFF → integrity → ON → FULL SHUTDOWN → MEMORIAL`. One step. MEMORIAL does not leave. ### Relation to runtime Softwares

FragGate is the door. `fraggate_call` with `slug=azinterface` is the agent path. This host’s `/mcp` is a pointer. ### How the three facts are supposed to agree

## 3. Security hardening

### What the interface trusts from the runtime

| Trust | Bound |
|-------|--------|
| Service binding `AZIEL_RUNTIME`, else `AZIEL_RUNTIME_ORIGIN` if it is `https://` | Door proxy and the optional pipeline cite |
| `GET /v1/fraggate` JSON | Attached as `runtime_cite` beside the local MASTER-33 object. Local `software_count`, `path`, and `lambgate: false` are not replaced |
| `GET /v1/software` | Suite card list, including `download_url`, when refresh succeeds |
| Mesh JSON | Homepage paints `enabled`, rollup counts, and node labels, and joins when `enabled` is true |
| GitHub REST | Star / fork / watcher numbers on the homepage, cached five minutes in KV |

`extractRuntimeArch` will set `runtime_cite.lambgate` true when the runtime body says so. The local field stays false. A client that prefers `runtime_cite` over the local object can be told a different hop story. The homepage banner does not read that object.

`proxyDoor` forwards `authorization` and `x-aziel-runtime-token` when the caller sent them, follows redirects, and returns the origin body with `X-Aziel-Door: proxy`. CORS on Interface responses is `*`. Any website can call the proxy. Mesh enable still depends on whatever the runtime requires. Mesh join, once radios are already on, does not add an Interface secret.

`_url_allowed` accepts every `https://` host, plus `http://127.0.0.1` and `http://localhost`. A catalog card whose `download_url` is a hostile archive is eligible for `pip install -e` or `npm install` when someone presses Start suite.

### Headers

Public homepage response observed 2026-10-05: `content-type` and CORS only. No CSP, no frame denial, no `nosniff`, no referrer policy, no permissions policy, no HSTS on that response. HTML is same-origin inline script plus an image from `https://www.azielcorpuslibrary.net/sigil.png`. Custody output is written with `textContent`.

`wrangler.toml`: `compatibility_date` `2026-09-06`, `observability.enabled` true, `head_sampling_rate` 1. `observability.traces.enabled` is unset, so traces are not turned on by the top-level flag. No `nodejs_compat`. No generated `Env` type. The Worker uses module-level `STATE`, which is shared across requests on one isolate. Account id and KV id are in the toml. They are identifiers, not API tokens. `workers/download-tracker/README.md` still says the KV id is the `0000…` placeholder. The toml id is `c7f3fab1…`.

### Download integrity

| Control | Present |
|---------|---------|
| Asset served from the Worker binding, not a 302 to GitHub | Yes |
| Allowlist of asset names | No. `?asset=` and `/download/{name}` become the ASSETS path after URL normalization |
| Digest in the page, the script, or the suite installer | No |
| Tar member `..` rejection on the suite unpacker | Yes |
| Size cap on suite downloads | 80 MB |
| Signature | No |

`/event` lets a caller increment counters for arbitrary owner/repo keys. That moves the breakdown, not the custody flags.

Genesis on the Worker and in Python is SHA-256 of a domain-separated seed, then the seed is dropped (`username_stored` false). The Flutter scaffold uses `String.hashCode` and stores that hex in memory. It is not the Worker hash, and it is not a shipped app.

### What a hostile tip can make the page claim

A tip that replaces aziel-runtime, or a catalog body the suite accepts, can:

- Make `/v1/fraggate`, `/v1/mesh`, and `/v1/runtime/*` say anything, because those bytes are proxied.
- Make `runtime_cite` on `pipeline_arch` carry a different strip, a true `lambgate`, or a different software count, **next to** the local 33.
- Make the Live Nodes strip say Mesh ON and list attacker-chosen labels, and cause the homepage to POST join.
- Make Start suite download and install an archive from any `https://` URL on a card.

A hostile tip cannot, through those proxies, rewrite the server-rendered banner. `notLiveSentence()`, the mail / kernel / boot sentences, and `software_count: slugs.length` are local. `path_report` ignores a caller who posts the live flags as true. Domain HTML for AZNet, AZMail, and AZ-OS stays on the not-live sentences baked in this repo.

The page can still be made to say the cycle is ON, because that sentence follows isolate `STATE` after a real `site_state_set`. That is the custody control, and the default remains OFF. `humanLines` will say “The username was stored.” if a payload’s `username_stored` field is true. The engine sets that field false. A proxied runtime body shown in a FragGate session pane is rendered by `humanLines` and can repeat whatever `display` the runtime returned.

## 4. Design philosophy

NO-LIE on this tip is the computed sentence plus ignored caller flags. The public banner and the AZNet tile say the alternative internet and the packet path are false, then say what is still missing. Present LAN hardware is described as this machine, and the second-device flag stays false.

The local desk (`suite_page.py`, `local_page.py`) is the quieter UI: system font, light and dark, 44px controls, focus rings, one next step per tile. The Worker page is the dense black/gold custody console (pipeline chips, 11 domains, every cycle button). The Flutter screen is a single list: cycle, integrity, genesis, hold, witness. It has no first-visit hint and no catalog count.

New-user copy on the Worker is the banner plus the numbered tarball steps. The suite tile for this product says it is already the running desk. Other tiles say “installed” only when `_find_exe` finds that product’s command on this computer. Otherwise the tile says needs-install, local-only, FragGate-only, or repair. AZMail, AZNet, and AZ-OS tiles say the public worker does not send mail, carry a packet path, or boot a kernel, and they offer the local desk actions with those limits in the sentence.
